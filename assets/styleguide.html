Outcome of a check

A check ends in one of five typed outcomes (ok, no_data, unavailable, error, skipped), so that “not checked” never reads as “clean”; until then it is queued or running. The same words appear in the hosts table and on the host page.

Results and states

A result is the answer of a check, and a passed one has a check mark. A state or a fact only says how things are; it stays grey, so that “Accepted” never reads like a pass: the risk is still there.
